This is an analysis and also an attempt at modelling a card-drafter for the Defect in the game Slay the Spire.

The dataset used comes from the devs themselves containing runs up to Nov 2020: 
https://www.reddit.com/r/slaythespire/comments/jt5y1w/77_million_runs_an_sts_metrics_dump/
This project uses a subset of this dataset, which is the data for A20 Defect runs in 2020
